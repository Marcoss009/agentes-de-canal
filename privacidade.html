Política de Privacidade — Agentes YouTube

Última atualização: 13 de outubro de 2026.

Quais dados são acessados

Com a autorização do proprietário, o aplicativo acessa pelas APIs do YouTube (YouTube API Services) os dados dos canais do próprio proprietário: informações do canal, lista de vídeos, estatísticas e relatórios do YouTube Analytics, e permissão para enviar e editar vídeos nesses canais.

Como os dados são usados

Os dados são usados exclusivamente para planejar, publicar e medir o desempenho do conteúdo dos canais do proprietário. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Armazenamento

Os tokens de acesso e as estatísticas ficam armazenados apenas no computador do proprietário. Nenhum servidor externo recebe esses dados.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os dados locais deixam de ser atualizados e podem ser apagados pelo proprietário.

Serviços do YouTube

Este aplicativo usa os YouTube API Services. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.
