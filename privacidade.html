Política de Privacidade — Agentes de Canal

Última atualização: 13 de outubro de 2026.

Uso dos Serviços de API do YouTube

O Agentes de Canal usa os Serviços de API do YouTube (YouTube API Services). Ao usar este aplicativo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

Quem usa

É uma ferramenta pessoal e interna, usada apenas pelo próprio desenvolvedor para gerenciar os seus dois canais (SuperKids Youtube e GTAzando_youtube). Não há outros usuários e o aplicativo não é distribuído.

Quais dados são acessados

  • Informações básicas dos canais do proprietário (nome, ID, contagem de vídeos e inscritos);
  • Lista de vídeos dos canais do proprietário e as estatísticas públicas desses vídeos;
  • Relatórios do YouTube Analytics dos canais do proprietário (visualizações, minutos assistidos, porcentagem assistida, inscritos ganhos);
  • Permissão para enviar vídeos, definir título, descrição, miniatura e horário de publicação nos canais do proprietário.

Como os dados são usados

Exclusivamente para planejar, enviar, agendar e medir o desempenho dos vídeos dos canais do proprietário. Todo vídeo é revisado e aprovado pelo proprietário antes de ser agendado.

Armazenamento e compartilhamento

Os tokens de acesso e as estatísticas ficam armazenados apenas no computador do proprietário. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou enviado a servidores externos. Não usamos cookies nem coletamos dados de visitantes deste site.

Retenção e exclusão

Estatísticas obtidas da API são atualizadas diariamente e as cópias locais com mais de 30 dias são substituídas ou apagadas. Para excluir todos os dados, o proprietário apaga a pasta local do aplicativo; para pedir a exclusão, escreva para o contato abaixo — a exclusão é feita em até 7 dias.

Como revogar o acesso

O acesso do aplicativo pode ser revogado a qualquer momento na página de permissões de segurança do Google: security.google.com/settings/security/permissions. Após a revogação, o aplicativo deixa de acessar os dados e as cópias locais são apagadas.
